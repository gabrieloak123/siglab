# Rótulos de triagem

Os skills usam cinco papéis de triagem. Em arquivos locais, registre o rótulo correspondente na linha `Status:` da tarefa.

| Papel do skill | Valor de `Status:` | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação |
| `needs-info` | `needs-info` | Aguarda mais informações |
| `ready-for-agent` | `ready-for-agent` | Está especificada para implementação por agente |
| `ready-for-human` | `ready-for-human` | Precisa de implementação humana |
| `wontfix` | `wontfix` | Não será implementada |

Quando um skill mencionar um papel de triagem, use o valor correspondente nesta tabela.
